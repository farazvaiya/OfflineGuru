# Full Autonomous Agent System Inventory (Baseline)

**Date:** 2026-11-17  
**Scope:** Repository discovery of `engineering_team/` autonomous engineering harness and agent ecosystem.  
**Method:** Static inspection of source/docs/config, DB/log inspection, and test discovery. No real (paid) LLM agent executions were performed in this verification session.

## 1. Discovery summary

- **Specialist agent roles defined in prompts/config:** 9 roles in `engineering_team/agents/AGENTS.md` (sections A–I) and 9 `[[agents]]` entries in `engineering_team/config/team.toml`.
- **Code-level runtime/execution components:** `harness/claude_runtime.py` (`AgentExecution`, real `claude` CLI subprocess adapter), `harness/claude_adapter.py` (`ClaudeCodeAdapter`), `harness/orchestrator.py` (`Orchestrator.execute_agent`), `harness/permissions.py`, `harness/workspace.py`, plus workflow managers (`task_manager`, `experiment_manager`, `benchmark`, `evaluator`, `report`, `state_machine`, `db`, `checkpoint`, `git_manager`, `discovery`).
- **Main harness DB evidence:** `engineering_team/state/engineering_team.db` contains 0 `agent_runs`, 21 problems/tasks, 30 experiments/evaluations/decisions, 40 benchmarks, 221 workflow_events (`sqlite` query via Python, 2026-11-17). This indicates workflow records exist but no persisted harness agent-run executions in the main DB.
- **Agent run logs present (test-generated/fake CLI):** `engineering_team/logs/agent_runs/*.log` include SUCCESS runs whose `executable` is `/tmp/pytest-of-faraz/.../fakebin/claude` (e.g. `4c0f231bd9d1.log`), consistent with mocked runtime tests rather than real LLM executions.

## 3. Agents not found / not implemented as distinct runtime agents

- No additional hidden specialist-agent classes implementing autonomous reasoning loops were found beyond the role definitions above and the generic `claude_runtime.AgentExecution` + orchestrator/managers. `harness/agent_runtime.py` is a **generic/deprecated-for-agent-labour** subprocess adapter (explicitly refuses recursive Claude launches) and is not the production Claude agent runtime.
- `engineering_harness/` (separate top-level directory) is a different/older harness (`engineering_harness/orchestrator.py` CLI state) and is **not** the `engineering_team` execution harness under review.
